# Commercial partner materials

Assessment: 27 November 2026.

EPC offer: pilot on supported systems, installer controls site safety and commissioning; welOS provides documented triage within agreed hours. Set SKU, fee, parts responsibility, optional referral margin, response windows, escalation and no automatic renewals. Developer offer: start on one consented representative building; report meter-level measured evidence before portfolio pricing. Customer offer: fixed diagnostic scope, clear data rights and a written end date.

Sales presentation sequence: service incident and measured cost; current workflow; proposed evidence gap; scope and access; economics; six-week success criteria; next decision. Onboarding: licensing, insurance, data owner authorization, system type, interface compatibility, site permissions, cost and SLA sign-off, incident and return workflow. Pilot planning example: INR 15,000 fee less INR 10,000 delivery and INR 1,500 partner allowance leaves INR 3,500 before tax and acquisition. Negotiate real costs and verify gross and contribution margin separately.
