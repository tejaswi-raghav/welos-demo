# Where welOS has to earn its place

Assessment: 27 November 2026.

| Alternative | Buyer gets today | welOS experiment | Evidence needed |
|---|---|---|---|
| Inverter manufacturer portal | Monitoring tied to installed equipment | Pair the same fault cases across supported brands | User tasks, time-to-diagnose, access permission |
| EPC maintenance contract | Trusted installer handles response | Add incident queue and documented handoff | Fewer unresolved incidents or repeat visits |
| Portfolio monitoring vendor | Multi-site operational tools | Test simpler small-EPC workflow with explicit per-site costs | Paid retention and support cost |
| Manual audit | Low deployment cost and familiar process | Compare time spent and actionable findings against a spreadsheet baseline | Blinded independent labels and actual labor |

Data rights, permissioned multi-brand integrations, verified intervention outcomes and delivery discipline could compound. None is demonstrated today. Pilot tags should include avoidable visits, support time, valid alarm, false alarm and evidence of resolution.
