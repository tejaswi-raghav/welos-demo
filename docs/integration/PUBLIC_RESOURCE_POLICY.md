# Public resource boundary

Only the explicit allowlist in scripts/export-business.mjs can enter the current website resource directory. Public vendor listing prices are distinct from private supplier quotations. The lab BOM is a public product-planning dataset, not a funding plan or claim of available cash.

Excluded by default: company five-year forecasts and cash plans, investor decks, founder biographical details, grant application drafts, private quotations, lead submissions and personally identifying inquiry data. Company experience uses a public editorial narrative and measurable roadmap without private model downloads.

Private local copy location is intentionally not embedded in this repository or public website. No access-control backend is invented. The existing demo sign-in is not used to protect investor material. Authorized private distribution must use an appropriately permissioned document service or a separately implemented, server-enforced authentication/authorization system.

Limit: earlier public commits, previous deployments and caches can retain previously published material. Removing current files does not retract history. No history rewrite, production settings change or deployment is performed by this branch.
